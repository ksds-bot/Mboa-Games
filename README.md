# Mboa Games 🇨🇲

**Le jeu est au village !** Une plateforme de jeux multijoueurs inspirée de l'ambiance et de la culture camerounaises.

## Stack
- Next.js 16 · React 19 · TypeScript
- Tailwind CSS 4
- Supabase (à connecter) : Auth, PostgreSQL et Realtime
- Vercel (déploiement prévu)

## Démarrage local
```bash
npm install
npm run dev
```
Ouvrir http://localhost:3000.

## État du projet
La première base de l'interface est en cours. Les parties multijoueurs, comptes, salons et sauvegarde des scores nécessitent la configuration du projet Supabase.
